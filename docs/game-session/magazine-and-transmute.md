# The magazine: what may be loaded

Part of [The game: a session](../game-session.md).

- **The magazine may only load a colour that is still hanging.** `RecountBallTypes` refills `_ballsOfType` after every landing and `RandomBallType` draws evenly among colours with a count above zero. It is the **next-colour policy handed to the shared `Magazine` as a delegate** (the Testbed draws over all thirteen), because the answer needs a map, level and rules. A colour that exists nowhere can only be parked: it grows the cluster, wastes a shot and can make a level **unwinnable**. Recounted per landing, not maintained incrementally (three places to get wrong). A colour with fewer than `MINIMUM_CLUSTER_SIZE` left is deliberately **not** dropped (that changes which levels are solvable: a difficulty decision). An empty map falls back to the default four. A ball counts only if `BallKinds.Matchable`: a rock wears a colour, and counting it would keep that colour in the queue with nothing able to complete it.
- **A loaded ball whose colour has died is re-coloured where it sits** (`Transmute`, over `Magazine.Recolour`): a stale queue costs up to `Magazine.SIZE` shots on colours that cannot match. The colour changes **immediately** (firing mid-fade gives the new one; the animation is cosmetic) and the replacement is random among survivors (picking the most helpful would quietly make the game easier). **It stops once the level is decided and once nothing is left to transmute *to*** (#176): the winning landing runs it before `CheckLevelCleared` arms the countdown, so the map is empty while the level is not yet decided (every clear re-coloured the queue as the field went). The gate is here, not only in `Shoot`'s refusal, because a landing can reach it with the gun shut.
- **The barrel never shows more rounds than shots left** (#262): `CollectMagazineBalls` clamps the drawn slots to `ScoreKeeper.ShotsRemaining`, as the HUD strip does. Draw-only; `Magazine.Advance` still deals every slot.
- **A slot moves whole** (#582): colour, kind, the colour it fades out of and the fade are one `MagazineSlot`, so shift, deal and swap move one struct (the swap once came apart as two one-way copies). The kind comes from a second injected policy (`NextLoadedKind`); both are handed over once so no shot allocates a delegate. `Refill` deals whole slots. `MagazineTests`.
- **The cross-fade is a dither**: a ball's colour is a per-draw uniform, so blending means drawing twice, and coincident translucent spheres would need sorting. `ModelInstance.Dissolve`: **zero draws the whole ball**, positive *goes*, negative *arrives*; the noise cell is in **display pixels** ("The ball dissolve dithers in display pixels" in `docs/rendering.md`). ⚠ `MagazineSlot.Transmute` counts **down** from 1, so progress is its complement (`TransmuteProgress`); fed straight it runs the effect backwards.
